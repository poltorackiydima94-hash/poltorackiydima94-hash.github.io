Privacy Policy

Last updated: November 10, 2026

Dimus Uploader uses the YouTube Data API and YouTube Analytics API only to manage the owner's own YouTube channels: uploading videos, setting metadata, thumbnails and playlists, posting comments, and reading channel statistics.

  • OAuth tokens are stored only on the owner's own computer and are never shared.
  • No data is sold, shared with third parties, or used for advertising.
  • No data is collected from other people.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API usage is subject to the YouTube Terms of Service and the Google Privacy Policy.
